PSYCHOLOGY COURSE FINDER

HOW TO RUN IT
1. Open the "dist" folder.
2. Double-click "index.html". It opens in any current web browser.
3. No installation, account, or web server is required.

HOW TO SHARE IT
Send the entire "dist" folder, or the ZIP file supplied with this project. The recipient should unzip it before opening index.html.

HOW IT WORKS
The app uses a local snapshot of Western Psychology's 2026-27 2000- and 3000-level course offerings.

Students use one search box. A course number produces related recommendations ranked by shared topic tags. A keyword or professor's name searches course titles, topic tags, descriptions, and instructors.

Keyword matching recognizes common word forms and plurals, so searches such as "animal" and "animals" or "memory" and "memories" produce the same results.

Each result includes an expandable prerequisite summary based on Western's current Academic Calendar. Students should verify prerequisites in the official calendar before registering.

The app does not scrape the department website live. Browsers normally prevent a local HTML file from reading an unrelated website, and PDF formats can change. Each recommendation links to the official course-outlines page for verification.

HOW TO UPDATE THE CATALOGUE
Open courses.js in a text editor. Course records are at the top of the file. Update course numbers, suffixes, titles, instructor names, descriptions, and topic tags as needed. Prerequisite summaries and topic definitions follow the catalogue.
